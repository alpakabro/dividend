# 월배당 포트폴리오 시뮬레이터

국내·미국 배당주와 ETF로 매달 배당을 받는 포트폴리오를 설계하고 분석하는 웹페이지입니다.

- 국내·미국 종목과 ETF 8,000여 개 검색, 일·주·월·연 차트와 차트·기업·실적·재무 분석
- 월배당 시뮬레이션, 보유 종목 평가손익, 포트폴리오 분석, 글로벌 매크로 브리핑, AI 조언(Claude 앱에서)
- 주가는 매일 아침 자동 갱신되는 종가 스냅샷(기준 날짜는 화면 머리말에 표시)이며 실시간 시세가 아닙니다.
- 입력한 보유 종목·비중은 각자의 브라우저에만 저장됩니다.

개발·수정 방법은 [CLAUDE.md](CLAUDE.md)를 보세요. (`app/` 소스 → `python3 app/build.py` → `index.html`)

이 분석은 참고용입니다.
